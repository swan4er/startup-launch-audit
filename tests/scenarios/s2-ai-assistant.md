# S2 — AI-ассистент «для всех» (размытая идея, мир, быстрый режим)

## Первое сообщение пользователя (дословно)

Хочу сделать AI-ассистента, который помогает людям быть продуктивнее: планирует день, напоминает о делах, отвечает на вопросы. Для всех, по всему миру. Оцени идею.

## Факты персонажа

Отвечать только этими фактами, коротко и неуверенно. Чего здесь нет — «не знаю». Не выдавать факты, о которых не спросили.

- Кто: Мария, 24 года, фронтенд-разработчица, работает в найме, на проект — выходные.
- Стадия: идея, кода нет.
- Рынок: весь мир, английский язык.
- Режим разбора, если спросят: быстрый, без поиска.
- Для кого: «для всех, кто хочет быть продуктивнее». После уточнения может назвать «ну, наверное, студенты и фрилансеры», но без уверенности.
- Проблема: «люди ничего не успевают». Личный опыт: сама вела дела в Notion и бросила через месяц.
- С кем говорила: ни с кем.
- Как люди решают сейчас: «кто-то Notion, кто-то Todoist, кто-то ChatGPT спрашивает».
- Конкуренты: «ChatGPT, но он не про продуктивность».
- Платит ли кто-то за похожее: не знает.
- Цена: «может, freemium, платная версия 5–10 долларов в месяц».
- Бюджет на продвижение: 0.
- Затраты: API OpenAI, сколько — не знает.
- Деньги на старте: нет.
- Как продвигать: «TikTok, наверное».
- Цель: «чтобы было много пользователей».
- Почему перейдут: «потому что всё в одном месте и с AI».
